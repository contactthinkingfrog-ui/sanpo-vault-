# カラー設計｜散歩する主夫

> 方向＝**A. ネイビー × テラコッタ**を「もっと絞る」で確定。
> **ネイビー主役＋クリーム地のミニマル**、テラコッタは**ごく稀なアクセント**。
> 緑を主役にしない独自配色で、ブランドの個性と独立性を担保する。

## 確定パレット（コア）

| 役割 | 変数 | HEX | 使い方 |
|---|---|---|---|
| 地（背景） | `--ss-cream` | `#F4EFE6` | 全体の60%。余白の主役 |
| 主色 | `--ss-navy` | `#1F3A4D` | 30%。ヘッダー・見出し・リンク・主要CTA・アイコン |
| 差し色 | `--ss-terra` | `#C2674A` | **10%未満。ごく稀に**。最重要アクション・強調・ホバーのポイントのみ |
| 文字 | `--ss-ink` | `#2B2A28` | 本文 |

> 基本は **ネイビー1色＋クリーム＋インク**で成立させ、テラコッタは「ここぞ」だけ。多用するとミニマルさが崩れる。

## 実装用 :root 変数（Cocoon子テーマ style.css に追加）

```css
:root {
  /* ブランド・コア */
  --ss-cream:     #F4EFE6; /* 地・背景 */
  --ss-surface:   #FCFAF5; /* カード面（地よりわずかに明るい） */
  --ss-ink:       #2B2A28; /* 本文テキスト */
  --ss-sub:       #6B6760; /* 補助テキスト（くすませた茶グレー） */
  --ss-line:      #E4DDD0; /* 罫線・カード枠（クリームに馴染む暖色ライン） */

  /* 主色：ネイビー */
  --ss-navy:      #1F3A4D; /* 主色 */
  --ss-navy-dark: #162C3B; /* ホバー・アクティブ */
  --ss-navy-tint: #E1E7EB; /* タグ・淡い背景セクション */

  /* 差し色：テラコッタ（ごく稀に） */
  --ss-terra:      #C2674A; /* アクセント */
  --ss-terra-dark: #A8543A; /* ホバー */
  --ss-terra-tint: #F3E2DB; /* 淡い強調背景 */

  /* レイアウト */
  --ss-radius: 12px;
  --ss-gap:    16px;
  --ss-maxw:   1080px;
}
```

## 使用ルール

- **60-30-10**：クリーム60／ネイビー30／テラコッタ10未満。
- **テラコッタは小さい文字に使わない**（中明度でコントラスト不足になりがち）。塗り・大きめのボタン・アイコンなど面で使い、その上の文字はクリームか白。
- **本文の強調・リンクはネイビー**で取る（テラコッタを乱用しない）。
- ボタン：主要＝ネイビー塗り＋クリーム文字／最重要1つだけテラコッタ塗り＋クリーム文字。
- コントラスト：ネイビー#1F3A4D × クリーム#F4EFE6 は十分（本文・見出しOK）。`--ss-sub` は補助テキスト専用（本文には使わない）。

## キャラクターとの関係
- キャラのエプロンのオリーブ／インディゴデニムは**キャラ固有色**でブランド色には含めない（[[wiki/design/キャラクター設定]]）。
- クリーム地にネイビー＆テラコッタが回る画面で、オリーブのエプロンはアースな差し色として自然に馴染む。**キャラは変更不要**。
- ヒーロー写真はこのパレットと喧嘩しない、くすみ／アース寄りのトーンを選ぶと統一感が出る。

## 配色の人格（このパレットが伝えるもの）
- `--ss-navy #1F3A4D` 主体＋クリーム＋テラコッタ稀＝落ち着き・大人・前向き・誠実。
- ネイビーは信頼と大人の落ち着き（MVVの「適性で選ぶ」「ハイセンスに」と整合）、テラコッタは家庭の温かみ、クリームは余白の品。
- 緑を主役に置かないことで、散歩する主夫だけの視覚的個性を確立する。
