# キャラクター設定資料｜散歩する主夫 公式マスコット

> 2026-06-13 確定。ナノバナナ（画像生成AI）で作成。確定画像はユーザー保有。
> 基本形（プレーン）を `wiki/design/assets/キャラ_基本形_プレーン.jpeg` に保存済み。差分（表情・タバコ版・無地エプロン・散歩ポーズ）は作成後に同フォルダへ追加。

## キャラクターの位置づけ
- **語り手＝著者本人をモデルにした主夫キャラ**（記事内に登場する案内役・語り手）。
- 一次情報メディアの顔。E-E-A-T（経験）の象徴であり、ブランドの世界観そのもの。
- 狙い：「主夫＝ダサい/情けない」のスティグマを「主夫＝ハイセンスでカッコいい」に反転させる（[[wiki/persona/README]] タカシ・ソラの引け目に直接効く）。

## 確定スペック

| 項目 | 内容 |
|---|---|
| 画風 | **洗練されたモダンなフラットイラスト**（ハイセンス・こなれた大人。量産アニメ風・劇画ラフ風はNG） |
| 線 | 細めで均一・なめらか・抜け感のある主線 |
| 塗り | フラット、陰影は最小限、余白のある上品な仕上がり |
| 頭身 | 3頭身寄り（スラッとした洗練デフォルメ。※コロッとした2頭身ではなくこの比率で確定） |
| 配色 | **くすみ系（ミュート）**。エプロン=セージグリーン／オリーブ、Tシャツ=オフホワイト（生成り）、デニム=インディゴ（裾ロールアップ）、スニーカー=白×ベージュ |
| 髪 | くるくるパーマの短髪（黒〜こげ茶） |
| 髭 | 短く薄め・きれいに整えた顎髭（濃くしない） |
| 表情 | 穏やかで品のある、こなれた涼しげな表情 |
| ポーズ | 余裕のある自然体の立ち姿 |
| 背景 | 白無地（切り抜き運用） |

## キャラ固有色とブランド配色の関係（2026-06-14 解決済み）
- **ブランド配色はネイビー主役で確定**（[[wiki/design/カラー設計]]：クリーム地×ネイビー×テラコッタ稀）。
- キャラのセージグリーン／オリーブのエプロン・インディゴデニムは**キャラ固有色**で、ブランド色には含めない。キャラは変更不要（クリーム地にオリーブのエプロンはアースな差し色として自然に馴染む）。
- 当初「セージグリーンを主色に」という暫定案は、緑リードを避けてブランドの独立性を担保するため**ネイビーへ差し替え済み**（経緯は [[logs/activity.md]] 2026-06-14）。

## 運用ルール
- **タバコ＝使い分け（B）**：プロフィール・生き方・散歩・SNSアイコンは「タバコあり版」、育児・健康・お金など実用記事の吹き出しは「タバコなし版」。確定の基本形は**タバコなし**。
- **エプロンのロゴ**：AI生成の文字は崩れるため、サイトで大きく使う素材は**正式ロゴに差し替え**る。汎用性のため**無地エプロンの素体**も持っておく。
- 記事内の吹き出しは1セクション1キャラ程度を目安に運用する。

## 作成プロンプト（再現用・A洗練フラット版）
ナノバナナに以下を入力（基本形）。詳細は [[logs/activity.md]] 2026-06-13 参照。
> 2頭身〜3頭身のデフォルメSDキャラ／洗練されたモダンなフラットイラスト／細く均一な線／くすみ配色（セージグリーンのエプロン・オフホワイトT・インディゴデニム・白ベージュのスニーカー）／くるくるパーマ短髪・薄く整えた顎髭・穏やかで品のある表情・自然体の立ち姿／白背景・全身・正方形
