# 読者ペルソナ｜散歩する主夫

「散歩する主夫」の読者は **主夫への距離（願望〜実行）と人生フェーズ** で3層に分かれる。
これは固定的な人物像ではなく、**読者がいま立っているフェーズの代表者**として扱う。

> リサーチ（[[wiki/research-summary]]）で実在が裏付けられた層をペルソナ化した。
> ユーザーの当初仮説（①キャリア伸び悩み既婚男性 ②価値観変化の20代男性）を核に、
> 伸びの本流である③兼業主夫/育休パパを収益の主読者として追加した。

## 記事生成時のお決まり手順

1. キーワードマップで該当KWを確認 → [[wiki/keyword-map]]
2. 本ファイルの比較表で対応ペルソナを判定（主読者1人＋副読者1人を明示）
3. 該当ペルソナの個別ファイルを読む（響く言葉・嫌う言葉・JTBD）
4. voice-guide を読みながら執筆 → [[wiki/voice-guide]]
5. お金・制度に触れるなら出典URL＋確認日を添える
