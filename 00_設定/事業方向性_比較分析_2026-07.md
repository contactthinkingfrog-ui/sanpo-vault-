# 事業方向性 比較分析｜散歩する主夫（2026-07-03）

> **決めること**：散歩する主夫をこのまま日本語メディアとして完成させるか、英語圏（訪日・在日外国人）向けに再定義するか。
> **決まっていること**：海外向けにする場合、ブランドは「散歩する主夫」の英語化（例：The Strolling Husband。キャラ・配色・ロゴ・世界観を直輸出）＝完全新規ブランドは起こさない（ユーザー確定 2026-07-03）。

---

## 1. 前提の整理

### 1-1. Reddit実証（2026-07-02）が検証したもの／していないもの

- 投稿「日本人が外国人の友達を作るには」（r/Advice・r/japanresidents）→ **表示3.4万・コメント123件・賛成票率73.2%・r/japanresidents当日3位**。
- **検証されたのは**：「在日外国人が日本人との接点・居場所を求めている」需要。＝**英語圏読者（案A）の需要**であり、対面ガイド/Airbnb構想の需要でもある。
- **検証されていないのは**：散歩する主夫の現設計（日本人男性向け・日本語SEO）の需要。こちらは依然 [[wiki/research-summary]] の「1〜2年後に立ち上がる」**仮説**のまま。
- 補足：Redditはユーザーの**唯一バズった実績のあるSNS**。日本語圏で同等の実績チャネルは現状ない。

### 1-2. 制度上の制約（どちらの案でも共通）

- 傷病手当金受給中は**1円でも報酬が発生したら受給資格を失う**（健保確認済み）→ **収益化は2026/12以降**。それまでは作り溜め・需要調査などの仕込みのみ（Hole/008_最新状態/仕事とお金 より転記）。
- つまり「今から2026/12まで＝約5ヶ月の仕込み期」はどちらの案でも同じ。方向を早く決めるほど仕込みが正しい方向に積まれる。

### 1-3. 旅後ポートフォリオとの整合（Hole/008_最新状態・2026-07-02）

| プロジェクト | 温度 |
|---|---|
| A：社不ライフ（日本語・SEO・アドセンス） | 惰性 |
| B：海外向けサイト（日本文化を伝える×POD） | **ワクワク** |
| C：対面ガイド/交流（Airbnb体験等） | **ワクワク** |
| D：日本語教師（ボランティア→月3万） | 検討中 |

- 現ポートフォリオに**散歩する主夫（日本語版）は入っていない**。日本語のまま完成させる場合、「日本語SEO×アドセンス」モデルを社不ライフと**2つ持つ**ことになる。
- 海外向けに再定義する場合、散歩する主夫＝**プロジェクトBの実体**になり、C（ガイド）/Airbnbの集客装置を兼ねる。ミッション「日本在住の外国人の居場所を現実/オンライン両方で増やす」（2026-07-02浮上）と一本につながる。

## 2. 案A：海外向け再定義（The Strolling Husband＝散歩する主夫の英語化）

### 読者と需要根拠

- 読者：在日外国人（日本人との接点・生活情報を求める層）／訪日リピーター／Japan interest層（日本の日常に興味がある英語圏読者）。
- 需要根拠：**Reddit実地データ（3.4万表示・賛成73.2%）＝実証済み**。「在日外国人側も孤独を感じている」証言がトップコメント群で計100票超（[[../Hole/008_最新状態/日本攻略]]攻略#4より転記）。
- コンテンツ：日本の主夫の日常一人称（散歩・手賀沼・庭・池・家事・季節）／日本の生活文化の内側解説／「日本人とどう繋がるか」（Reddit投稿の延長）／ローカル案内（我孫子・北総・東京東側）。

### 差別化

- 英語圏の「Japan系」大手（Tofugu・GaijinPot・Unseen Japan等）は**外国人が書く日本**。「**日本人主夫本人の一人称**」は構造的に競合が書けない。
- 近接例：YouTube「[Samurai Life of Stay At Home Dad](https://www.youtube.com/c/samurailifeofstayathomedad)」（日本人主夫の英語発信）が存在＝**ジャンルとして成立する証拠**。ただし同チャンネルはマレーシア移住者で「日本国内の日常」枠は空いている。（確認日 2026-07-03）

### 収益モデル（3本柱＝アドセンス一本足にしない）

| 柱 | 数字（確認日 2026-07-03） |
|---|---|
| AdSense | **米国RPM約$6.34 vs 日本約$3.22＝約2倍**（[Partnerkin 2026](https://partnerkin.com/en/blog/articles/adsense_rpm_rates_by_country)）。CPCは米$0.61 vs 日$0.14（[World Population Review](https://worldpopulationreview.com/country-rankings/adsense-cpc-rates-by-country)） |
| POD（手描きキャラグッズ） | 良好な利益率の目安30〜50%（[Printful](https://www.printful.com/blog/what-is-a-good-profit-margin-for-print-on-demand)）。実売の平均像：アクティブセラーで月$500〜2,000、ただし**月$500到達に3〜6ヶ月・200点規模の出品が前提**（[Merch Titans 2026](https://merchtitans.com/blog/print-on-demand-profit-margins-guide)）＝甘くない。キャラ資産があるぶん出品コストは低い |
| ガイド/Airbnb導線 | サイト＝「この人に会いに行ける」受け皿。C構想（3時間5,000円）・Airbnb（軌道後 月5〜7万試算・大家承諾が関門）への集客装置。収益はサイト外で立つ |

### 流用できる資産／作り直すもの

| 流用できる（≒デザインフェーズの成果はほぼ生存） | 作り直す（戦略レイヤー） |
|---|---|
| 配色（ネイビー×クリーム×テラコッタ・--ss-*変数） | ペルソナ3体（日本人男性→英語圏読者に全差し替え） |
| キャラクター（手描き・著者本人モデル）→PODと直結 | keyword-map（日本語KW→英語圏の検索/コミュニティ動線） |
| ロゴ設計の考え方・足あとファビコン | voice-guide（英語の声を新規定義） |
| トップ/カテゴリ/記事ページ設計・共通土台CSS | content-architecture（お金・制度記事の柱を廃止→日常/文化/繋がり軸へ） |
| Cocoon実装ノウハウ・サーバー・Wiki運用方式 | 収益化方針（アドセンス主軸→3本柱） |
| 一次写真・散歩という世界観 | 固定ページ本文（英語）・法務ページ（対象国配慮） |

### リスク（正直に）

1. **英語SEOの競合は濃い**うえ、AI検索の逆風は英語圏が最前線（→セクション4）。**SEO一本足では勝てない前提で、Reddit/コミュニティ起点の設計が必須**。
2. **Redditは宣伝に厳しい**（自己宣伝比率ルール・sub毎の規制）。「投稿がバズった人」と「サイトに誘導する人」は扱いが別。導線は「プロフィール経由・求められたら共有」等の設計が要る。
3. **英語執筆コスト**：本人の一人称の生々しさが価値なので、機械翻訳丸投げは不可。日本語で書く→Claudeが英語化→本人が声を確認、の体制設計が必要。
4. POD平均収益の数字は「多数出品×継続」前提。キャラ1体で自動的に売れる話ではない。

## 3. 案B：日本語のまま完成させる

### 利点

- **設計資産100%流用**：ペルソナ・KWマップ・voice-guide・コンテンツ設計・収益化方針まで全部完成済み。残りはCocoon実装→執筆のみで最短距離。
- 日本語で書ける（執筆コスト最小・声の再現が容易）。
- 需要仮説は**方向として健在**（確認日 2026-07-03）：
  - 第3号被保険者の男性（≒被扶養の主夫）**約13万人・30年で3倍**（[日本経済新聞](https://www.nikkei.com/article/DGXZQOUA049L60U6A600C2000000/)）
  - 10〜30代男性の**約6割が専業主夫願望**（[SheepDog調査・PR TIMES](https://prtimes.jp/main/html/rd/p/000000023.000077217.html)）、既婚男性68.93%（[マイナビニュース 2021](https://news.mynavi.jp/article/20210716-1923255/)）
  - 主夫の8割が兼業（[@DIME](https://dime.jp/genre/1350867/)）＝ダイキ（兼業主夫ペルソナ）路線と整合

### リスク

1. **需要の時期は依然仮説**：「1〜2年後に検索需要が立ち上がる」は裏付けの傾向はあるが、立ち上がり時期・規模は未確定。波が来るまで低PV期間を耐える前提。
2. **収益モデルがアドセンス主軸＝PV依存**：AI検索の打撃（→セクション4）を**最も受けやすいモデル**。単価も英語圏の約半分。
3. **ポートフォリオ重複**：日本語SEO×アドセンスは社不ライフ（温度＝惰性）と同型。同じモデルを2サイト運転する体力配分の問題。
4. **本人の温度**：旅後の「ワクワク」はB/C（海外・対面）に向いている。散歩する主夫（日本語）は旅前の設計で、旅後のプロジェクト一覧に入っていない。ストック型事業は「続ける力」が生命線（[[../Hole/008_最新状態/仕事とお金]]の軸）なので、温度は無視できない変数。

## 4. 両案共通のリスク：AI検索による「SEOブログ」の構造変化（確認日 2026-07-03）

- AI Overviews表示時、検索1位のCTRは**7.3%→1.6%**に低下（[ALM Corp／反トラスト訴訟資料の分析](https://almcorp.com/blog/google-ai-overviews-publisher-traffic-decline-antitrust-lawsuit-analysis/)）。ゼロクリック検索は**全クエリの69%**（Similarweb、[Digiday](https://digiday.com/media/google-ai-overviews-linked-to-25-drop-in-publisher-referral-traffic-new-data-shows/)）。
- 個人ブログの実例：老舗旅行ブログ The Planet D は流入-90%で**閉鎖**（[SmartFrame](https://smartframe.io/blog/google-ai-traffic-drop-heres-what-publishers-are-doing-about-it/)）。
- 一方で **Redditは成長側**：DAU約1.16億・前年比+19%、**AIツールの引用元No.1ドメイン**（[Wytlabs](https://wytlabs.com/blog/reddit-statistics/)／[Foundation](https://foundationinc.co/lab/reddit-statistics/)）。
- **含意**：
  - 「検索流入×アドセンス」だけのメディアは、どちらの言語でも2026年時点で逆風。
  - 生き残る型は「**AIに要約されない一次体験（一人称・写真・実在の場所と人）**」＋「**コミュニティ/直接読者（Reddit・ニュースレター）起点**」＋「**PVに依存しない収益（グッズ・ガイド・宿泊）**」。
  - この3条件は**案Aの設計と自然に一致**する（案Bでも取り込めるが、収益化方針の主軸=アドセンスを再設計する必要が出る）。

## 5. 比較表・判断基準・推奨

### 定量・定性比較

| 軸 | 案A：海外向け再定義 | 案B：日本語のまま完成 |
|---|---|---|
| 需要の実証 | **◎ 実証済み**（Reddit 3.4万表示） | △ 仮説（傾向データはあるが時期未確定） |
| 広告単価 | **◎ 日本の約2倍**（RPM $6.34 vs $3.22） | △ |
| 収益の分散 | **◎ 3本柱**（広告+POD+ガイド/宿泊） | × アドセンス主軸＝PV依存 |
| AI検索リスク耐性 | ○（コミュニティ起点+PV非依存収益で設計） | × 直撃するモデル |
| 設計資産の流用 | ○ デザイン層は生存・戦略層は再設計 | **◎ 100%流用・最短距離** |
| 執筆コスト | △ 英語化の体制が要る | **◎ 母語** |
| 競合 | △ 濃い（ただし「日本人主夫の一人称」は空白） | ○ 空白ジャンル（波待ち） |
| 本人の温度 | **◎ ワクワク（B/Cと一本化）** | △ 旅後リストに不在 |
| 他プロジェクト相乗 | **◎ B/C/Airbnb/ミッションと直結** | × 社不ライフと重複 |
| 実績チャネル | **◎ Reddit（唯一バズったSNS）がそのまま主戦場** | × 日本語圏に実績チャネルなし |

### 判断基準（1行）

- 「**検索需要の波に先回りするメディア事業**」をやりたいなら→案B。
- 「**実証済みの読者×複数収益源×居場所づくりミッション**」をやりたいなら→案A。

### 推奨：**案A（海外向け再定義）**。ただし条件付き

推奨理由は上表の通り（需要実証・単価・収益分散・温度・ポートフォリオ整合の5点で案Aが優位）。ただし次の3条件を設計に組み込むこと：

1. **「英語SEOブログ」ではなく「コミュニティ起点のホームベース」として設計する**。集客の主戦場はReddit（実績あり）＋αで、サイトは「深く知る・グッズを買う・会いに来る」受け皿。SEOは従。
2. **収益はPV非依存の柱（POD・ガイド/Airbnb導線）を最初から組み込む**。アドセンスは添え物。
3. **日本語版は「廃止」でなく「棚上げ」**。ペルソナ・KWマップ等の日本語資産は保管庫に残す（消えない）。1〜2年後に主夫需要の波が実際に来たら、その時の体力で再開判断できる。

## 6. 決定後の行程（どちらに決めても、最後はOpus向け実装指示書に落とす）

### 案Aに決めた場合

1. **戦略改訂**：MVV・メディア戦略の英語圏版（ミッション「日本在住外国人の居場所を増やす」を組み込む）→ 00_設定/ 改訂
2. **ペルソナ再設計**：在日外国人・訪日リピーター・Japan interest層の3体（Redditコメント123件が一次資料になる）
3. **コンテンツ設計**：Reddit起点の動線設計＋英語コンテンツマップ（日常一人称/文化解説/繋がり方/ローカル案内）
4. **voice-guide（英語）**＋執筆体制（日本語で書く→英語化→本人確認）の定義
5. **収益設計**：POD（出品計画・プラットフォーム選定）／ガイド・Airbnb導線／AdSense
6. **技術判断**：ドメイン（shufu-sanpo.com継続 or 英語圏向け新ドメイン）・WordPress/Cocoonの英語運用可否
7. **Opus向け実装指示書**：上記確定後、サイト実装（CSS/トップ/カテゴリ/記事テンプレ）を曖昧さゼロの仕様書に落とす

### 案Bに決めた場合

1. 残宿題の解消：KW検索ボリューム実数化・利用ASP確定
2. 記事テンプレート＋運用ルールdoc整備
3. **Opus向け実装指示書**：Cocoon子テーマ（共通土台CSS→トップ→カテゴリ→記事部品）を設計済みドキュメントから仕様書化
4. フェーズ5（旗艦記事3本）へ
- ※AI検索リスクを踏まえ、[[00_設定/収益化方針]]のアドセンス主軸は再検討を推奨（案Bでも）
