### ⬜ STEP 4 — どう届けるか決める

> ⚠️**ここはまだ何も決まっていない。** 2026-07-31時点でClaudeが一度「Redditを主戦場から降ろす」と書いたが、**調べる前に決めていたので取り消した**。候補は全部フラットに戻っている。

**1つずつ調べる候補**（順不同）：

| 候補 | 見ること |
|---|---|
| Reddit | 現アカウントで何ができるか／続けられる形はあるか／一発の投稿の価値 |
| note（日本語） | 日本語で書く器として意味があるか |
| 海外のnote的サービス | Medium・Substack など。転載か、独立の器か |
| その他の海外SNS | どれが「書く以外の労働」を要求しないか |
| 広告（お金を払う） | 出す価値があるのか。いくらで何が返るのか |
| Pinterest | 画像を作る手間と、返ってくる流入の割 |
| メール（ニュースレター） | いつ始めるか |
| 検索（SEO）・AI検索の引用 | すでに土俵は合っている（STEP 3で確認済み） |

**各候補について必ずセットで出すもの**：①何を要求されるか（手間・社交の量）②何が返ってくるか（実例・数字）③やめ時（撤退基準）。
**撤退基準のないチャネルは始めない**（過去サイトの失敗の型）。
成果物＝チャネル調査＋選定（新規作成予定）
