## §00 ★★★「AIをどう使って事業を成立させたか」の実例（2026-08-04 実査）

> **本人＝「AIというテーマには一切関係ない。AIをどのように活用してビジネスを成立させたかが重要。特にClaudeの事例なら私にもできる」。**

### 00-1. ★★実例1：Flowly.run ＝「**流通の70%をAIが回している。その正確なスタック**」

**[出典＝Indie Hackers](https://www.indiehackers.com/post/ai-runs-70-of-my-distribution-the-exact-stack-fda9c0d2c9)。** 事業＝フリーランス/個人事業主向けの生産性ツール。**★TSHに最も近い実例＝「作る」ではなく「届ける」をAIに任せた例。**

**AIがやっていること（cronで回る5本のPythonスクリプト）**

| # | 中身 |
|---|---|
| 1 | **受信箱の監視**＝2時間ごとにGmailを見て、記者からの問い合わせを**Claude Haikuで自分の立場に照らして採点** |
| 2 | **スレッド巡回**＝HN・X・Blueskyを1日3回引いて、**候補と「返信の切り口」案**を返す |
| 3 | **下書きパック生成**＝1日の終わりに、**声の定義書＋制約リスト**を使って、各チャネル向けに**編集すればすぐ出せる下書きを5本** |
| 4 | **日次ダイジェスト**＝アクセス解析を引いて21時にメール |
| 5 | **返信ドラフト**＝記者への返信を60語制約で書く。★**送信前に必ずワンクリック承認で止まる** |

**★人間が手放さなかった12個**（理由＝**この12個が売上を作っているから**）

> 返信の最後の30%の編集／AIの下書き5本から出す1〜2本を選ぶ／自分の立ち位置に関わる判断／**顧客とのDM・メール全部**／名指しの相手への連絡／**自分の投稿へのコメント**／**他人の名前が出る返信すべて**／競合との位置取り／締めの一文

**★「絶対に書かないことリスト」（Never-Write List）**

> 「**Great question.** で返信を始めるな」「**leverage / unlock / synergy / in the trenches** を使うな」
> 最初の80%で自社製品に触れない／引用以外で絵文字を使わない／X・HN向けは1文25語以内

**★★結果（ここが本題）**

| | |
|---|---|
| コスト | **月$400 → 月$19** |
| 取り戻した時間 | **週14時間** |
| ★**有料顧客を生んだのは** | ★**人間が持ち続けた12個だけ** |
| ★**月$400のAIツール群による登録増** | ★**測定可能な増加はゼロ** |

> ★★★**AIが流通の70%を回して、コストを95%下げ、週14時間を返した。それでも売上は人間の30%からしか出なかった。**

### 00-2. ★実例2：Claude Code で作っているソロ開発者たち

**[Indie Hackers](https://www.indiehackers.com/post/i-built-an-enterprise-ai-chatbot-platform-solo-6-microservices-7-channels-and-claude-code-as-my-co-developer-5bafd24c20)ほか＋[Anthropic自身の調査](https://www.anthropic.com/research/claude-code-expertise)**

| 分かったこと | 中身 |
|---|---|
| ★**分業の原則** | **人間が「何をやるか（計画）」の判断をし、Claudeが「どうやるか（実行）」の判断をする。★人間の専門性が高いほど、1回の指示でClaudeがやる仕事が増える** |
| ★**3〜4週目に必ず起きること** | ★★**「AIが、前に決めたことと矛盾する判断を出し始める。出力が不安定になり、作るより直す時間が増える」** |
| ★**その対策** | ★**CLAUDE.md に不変条件（invariants）を先に書く**＝使う技術・常に守るパターン・**絶対に生成してはいけないアンチパターン**。これでセッションをまたいでも一貫する |
| **役割の勘違い** | **AIは「速いエンジニア」であって「プロダクトオーナー」ではない。要件・テスト方針・全体の挙動は人間が持つ。AIは言われた通りに作る。「これが失敗したらどうなる？」と誰も言わなかったから、言わなかった** |
| ★**最後に残る壁** | ★**「一番難しいのは作ることではなく流通。AIは作れるが、信用を近道させることはできない」** |

### 00-3. ★★これがTSHにとって意味すること＝**必要なものは、もう保管庫にある**

| 実例で「これが要る」とされたもの | TSHの現物 |
|---|---|
| **声の定義書 ＋ 制約リスト** | ★**[[wiki/voice-guide-en]] のNG集**（em dash禁止／「It's not X, it's Y」禁止／AI頻出語禁止／絵文字と「!」連発の禁止）＝**Never-Write Listと同じもの。実地で2回AI判定された経験から作ってある** |
| **CLAUDE.md に不変条件を書く** | ★**[[CLAUDE.md]] ＋ [[00_設定/引き継ぎ_Opus_2026-08]] §3「決まっていること」＝まさにこれ** |
| **3〜4週目にAIが前の決定と矛盾し始める** | ★★**2026-08-03に実際に起きた**（Claudeが1セッションで8回結論を撤回）。**対策として §3の突き合わせルールを常設した＝業界の標準的な対策と同じものに、独立に到達していた** |
| **送信前にワンクリック承認で止める** | ★**記事制作ワークフロー＝本人確認を経ないと公開されない**（既にそうなっている） |
| **人間が手放さないもの＝売上を作る部分** | ⚠️**TSHではここが未定義。「本人が絶対に自分でやること」のリストが無い**（→下記） |

### 00-4. ⚠️そこから出た宿題（1つだけ）

> ★**「本人が絶対に手放さないことリスト」を作る。**
> Flowly.run の実例＝**AIが70%回しても、金は人間の30%からしか出なかった。** そして**その30%が何かは、事前に決めて守られていた。**
> TSHの現状＝**素材出しと確認は本人**と決まっているが、**「これはAIに渡さない」の明示リストは無い。**
> → **B6（声）またはSTEP 9（運用）で作る。ここでは決めない。**

## §1 ★★AIで事業をやるときの原理（1行）

> **AIは「作るコスト」を下げる。「何を作るべきか」と「誰に届けるか」のコストは下げない。**

作ることが安くなると、**希少なものが3つに移る**（[Indie Hackers](https://www.indiehackers.com/post/are-we-entering-the-era-of-solo-founders-e896255761)ほか）：

| # | 新しい希少資源 | 中身 |
|---|---|---|
| **1** | ★**判断** | **何を作らないか**を決めること。「モデルが何かを見る前に起きる決定が、出力が編集する価値のあるものかどうかを決める。これはプロンプトで回避できるスコープの問題ではなく、何が重要かの判断」 |
| **2** | ★**流通** | **出したことを誰も気にしない。** 届ける経路がなければ、作ったものは存在しないのと同じ |
| **3** | ★**自分の注意力** | 情報財の複製の限界費用がゼロに近づく環境では、**生産ではなく注意力が拘束条件になる** |

> ★**含意＝AIを導入して増えるのは「生産量」だけ。判断・流通・注意力は1ミリも改善しない。**
> **そして事業が死ぬのは、たいてい生産量が足りないからではない。**

## §2 メディアの収益モデル ＝ 何がどれだけ動いているか（実データ）

### 2-1. ★大手出版社の2026年（[Digiday+ Research](https://digiday.com/media/digiday-research-how-dow-jones-forbes-the-guardian-and-other-publisher-revenue-streams-are-shifting-in-2026/)）

**出版社が注力している度合い（加重平均）**

| 収益源 | 2026 | 動き |
|---|---|---|
| **直販広告**（direct-sold） | **3.67** | 最重視 |
| ブランデッドコンテンツ | 3.17 | |
| **サブスクリプション** | 2.67 | ★**収益がある出版社が56%（2024 Q1）→70%（2025 Q1）** |
| プログラマティック広告 | 2.61 | |
| イベント | 2.42 | ★**アフィリエイトを追い抜いた**（2.16→2.42） |
| 動画広告 | 2.28 | |
| ★**アフィリエイトコマース** | ★**1.28** | ★★**急落（2.42→1.28）** |

> ★**アフィリエイト急落の理由が明記されている＝AI Overviewsが要約で答えるので、製品レビューや推薦にクリックする必要がなくなった。**
> 「**独自の分析や独自データを持つ出版社はトラフィックを保持しやすく、AI引用も得られる。ただしそれでも打撃は受ける。**」

### 2-2. 個人・ニッチサイトの側（[Authority Hacker のアフィリエイター2,270人調査](https://www.authorityhacker.com/affiliate-marketing-survey/)ほか）

- **年6桁ドル以上を稼ぐサイトの82%は、ディスプレイ広告とアフィリエイトの併用**＝**小規模ではまだこれが標準**。
- **メールリストが「最も収益性の高い可能性のある方法」**とされる。
- ★**2026年のトレンド＝一回きりの成果報酬より、12〜24ヶ月または生涯の継続報酬（recurring）。複利で効くため。**
- ⚠️**出典の割引**：Authority Hacker・Niche Pursuits は**教材を売っている側**。ただし2,270人の調査は実データで、方向はDigidayと矛盾しない。

### 2-3. ★2つのデータをどう読むか（矛盾していない）

| | 大手（Digiday） | 個人（Authority Hacker） |
|---|---|---|
| アフィリエイト | **急落（2.42→1.28）** | **まだ標準（6桁サイトの82%が併用）** |

- **大手のアフィ＝製品レビュー・コマース**＝**AI Overviewsの製品要約に最も直接食われる帯**。
- **個人の82%＝生き残っているサイトのスナップショット**（生存者のみを数えている）であって、トレンドではない。
- ★**両者が一致している点は1つ＝「広告＋アフィだけへの集中が脆い。逃げ道はメール・自社商品・継続報酬」。**

## §3 ★価値はどこへ移るか

情報の複製コストがゼロに近づくと、**価値は「情報そのもの」から離れる**。実データで観測されているのは：

| 移動先 | 根拠 |
|---|---|
| **信頼とブランドの権威** | 「ブランドの権威と信頼が、出版社の新しいAI資産になりつつある」（Digiday） |
| **直接の関係（メール・購読）** | サブスク保有出版社 56%→70%。個人側でも「メールリストが最も収益性が高い可能性」 |
| **その場でしか得られないもの（イベント）** | イベントがアフィリエイトを追い抜いた |
| **独自データ・一次体験** | Googleのノンコモディティ定義／2026年3月・5月のコアアップデート |

## §4 TSHへの当てはめ（⚠️ここでは決めない・申し送りのみ）

### 4-1. ★今わかっている構造上のリスク＝**収益が集中している**

現行の柱（Claudeの提案・本人未承認）＝**①広告（床）②通信 ③事前予約 ④在住者の金と生活**。

> ⚠️★**②③④は全部アフィリエイト。①はプログラマティック広告。**
> **＝4本柱のうち3本が、2026年に業界で最も急落している収益源に集中している。**
> **そして残り1本も、AI要約に食われている側。**

**独立した2本の線が、同じことを指している：**

| # | 線 |
|---|---|
| 1 | **Digiday**＝アフィリエイトコマースが 2.42→1.28 に急落（AI Overviewsが原因と明記） |
| 2 | **Empire Flippersの買い手**＝「**広告だけ／アフィだけは single point of failure**」（サイトを買う人が実際に金を出すときの判断基準） |

⚠️**ただし反対材料もある（1つの発見で結論を出さない）：**
- 保管庫の実測＝**Japlanease（個人）は通信＋事前予約＋自著で回っている／Tokyo Cheapoは広告主体＋直接提携**。**小規模ではまだ機能している**（2026-08-03に実物確認済み）。
- 「独自の分析・独自データを持つ出版社はトラフィックを保持しやすい」＝**TSHの差別化が効く側**。
- TSHの必要額は**月10万円**＝大手出版社とは桁が違う。**絶対額が小さければ成立しうる。**

→ ★**結論＝「アフィが死んだ」ではない。「TSHの収益が分散していない」。これはSTEP 6（換算式の作り直し）で扱う。**

### 4-2. すぐ効く発見（STEP 6で使う）

- ★**継続報酬（recurring）を優先する。** 現行の柱で該当＝**Wise（クッキー365日）／JapanesePod101（永久クッキー）**。一回きりの成果報酬（Sakura Mobile ¥2,000/件など）より複利で効く。
- ★**メール（NL）の位置づけは「収入源ではなく資産」で正しかった**（NL広告は購読者1,000人で年約$252＝2026-08-03に実数確認済み）。**ただし"逃げ道"としての価値は、今回のデータでむしろ上がった。**

### 4-3. ⚠️流通が空いている

- 希少資源の2番目＝**流通**。**TSHは現在、検索一本。STEP 4（チャネル）がまだ空。**
- Digidayも Empire Flippersも「**流入経路の分散**」を条件に挙げている。
- → **STEP 4はやらないと埋まらない穴。** ⚠️**ただしここでは決めない**（2026-07-31に調べる前に決めて取り下げた前例がある）。
