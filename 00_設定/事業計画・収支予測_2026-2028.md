# 事業計画・収支予測｜The Strolling Husband

> **結論を先に**：現金リスクはほぼゼロ、実体は「時間の投資」。標準シナリオは**2027年末で月2〜4万円**（＝月8万目標は楽観シナリオ）。純粋な金銭リターンだけならパートに劣るが、(1)ストック性 (2)実証済みの需要 (3)ガイド/Airbnb/日本語教師と同じ読者への一本の導線、を含めれば**育てる価値あり。ただし下記チェックポイントで機械的に判定し、情が入った延命をしない**。

---

## 1. 投資の正体

| 項目 | 金額/量 |
|---|---|
| 現金投資 | **年約2,000円**（ドメイン代のみ。サーバー共用・テーマ無料・POD在庫ゼロ） |
| 時間投資（仕込み期 2026/7〜12） | 週10〜15時間 × 約22週 ≒ **250〜330時間**（記事25本×5h＋PODデザイン50点＋Reddit週次＋実装レビュー） |
| 時間投資（2027年） | 週8〜12時間 ≒ **400〜600時間** |
| 健康コスト | 回復期・慢性消耗に注意（Hole/体調と再発防止）。**週次時間上限を守ることが投資保全** |

- **最大のリスクは金ではなく「18ヶ月の時間を需要のない場所に沈めること」**（本人の原則：ブログ等は約8割が月1万円未満で脱落＝Hole/仕事とお金）。だからこの計画はチェックポイント（§5）で縛る。

## 2. 前提（すべて仮定として明示。四半期レビューで実数に置換）

| 変数 | 仮定値 | 根拠 |
|---|---|---|
| 広告RPM（実効） | **$4〜6/千PV** | 米単体$6.34（[Partnerkin](https://partnerkin.com/en/blog/articles/adsense_rpm_rates_by_country)・確認2026-07-03）。読者に在日層（日本配信）が混ざるため割引 |
| アフィ収益 | Ch.0系記事PVの2〜3%がクリック→3〜5%成約・平均報酬¥500〜2,000 | eSIM単価小・JRPass/体験は高単価（[収益化方針の実額](00_設定/収益化方針_英語圏版.md)） |
| POD | 2027年末 月10〜40件・平均粗利¥700/件 | セラー実効$5〜8/枚（[Merch Titans](https://merchtitans.com/blog/print-on-demand-profit-margins-guide)）。Etsy内発見＋サイト導線 |
| トラフィック立ち上がり | 新規英語サイト：6ヶ月で月3〜5千PV、12ヶ月で1〜2万PV（コンテンツが当たる前提） | 仮定。AI検索逆風で従来相場より保守的に置く |
| Reddit→サイト転換 | 表示の0.5〜2%が訪問 | 仮定（6.6万表示→300〜1,300訪問/バズ相当） |

**構造リスク（направление自体への逆風）**：
- 柱1・3の「手順もの」は**AI Overviewsに最も要約されやすいタイプ**。ゼロクリック69%（[Digiday](https://digiday.com/media/google-ai-overviews-linked-to-25-drop-in-publisher-referral-traffic-new-data-shows/)・確認2026-07-03）。→ 防御は一次写真・一人称・実在店舗・Reddit直行読者（設計済みだが、効くかは実測）。
- バズは**n=1**。再現性は未検証（§5チェックポイント1で最初に検証する）。

## 3. シナリオ別収支（2027年末時点の月次）

| | 悲観（確率感 ~35%） | **標準（~45%）** | 楽観（~20%） |
|---|---|---|---|
| 月PV | 4千 | 2万 | 6万 |
| 広告 | ¥2,500 | ¥13,000 | ¥40,000 |
| アフィ | ¥2,000 | ¥8,000 | ¥20,000 |
| POD | ¥3,000 | ¥9,000 | ¥25,000 |
| **月計** | **¥7,500** | **¥30,000** | **¥85,000** |
| 状態 | Reddit再現せず・検索も薄い | 柱1〜2が刺さり定常流入 | バズ再現×アフィ成約良好＝**月8万目標達成** |

- **期待値（加重平均）≒ 月3.3万円（2027年末）**。2028年は記事資産の複利で標準シナリオ月4〜6万を想定（メンテ工数は週5h程度に低下＝ストック型の本領）。
- **時間対効果の正直な比較**：仕込み〜2027年末の投下 ≒ 700〜900時間。標準シナリオの2027年収益 ≒ 20〜25万円 → **1年目の実効時給は数百円**。同じ時間をパートに使えば70〜90万円。**金銭だけなら1年目はパートが圧勝**。この投資が正当化されるのは (a) 2年目以降の複利 (b) 下記の非金銭リターンがあるから。

## 4. 非金銭リターン（このプロジェクト固有の"配当"）

1. **導線資産**：将来のガイド・Airbnb・日本語教師（プロジェクトC/D）の見込み客と、サイトの読者が**同一人物**。月2万PVは「会いに来る人・生徒・ゲスト」の供給源＝他プロジェクトのCAC（集客コスト）をゼロにする。
2. **英語の実戦**（本人の学習目標と一致）・**外国人との接点**（weak ties・居場所ミッションのオンライン側）。
3. **「暇＋金＋締切」で回る本人適性**との一致・ワクワク（継続の燃料。惰性の社不ライフとの最大の差）。
4. 傷病手当期間（〜2026/12）は**収入を得てはいけない期間**＝時間の機会費用が構造的に低い今が、仕込みの最適タイミング。

## 5. チェックポイント（機械的に判定・情で延命しない）

| 時期 | ゲート | 未達なら |
|---|---|---|
| **CP1: 2026/9末** | Reddit再現性：オリジナル投稿3本で表示1万超が1本以上 ＆ 記事10本を健康を崩さず書けている | 柱の配分見直し（Reddit依存を下げ検索寄せ）。健康未達なら週時間を即減 |
| **CP2: 2026/12末** | 記事20本以上・POD30点以上・収益化の準備完了 | 未達分だけ公開時期を後ろへ（質を落とさない） |
| **CP3: 2027/3末** | 月3千PV以上 or Etsy初売上10件 | どちらもゼロなら**内容ピボット検討**（当たった記事タイプに全寄せ） |
| **CP4: 2027/9末** | **月収益1万円以上** | 未達なら**縮小判定**：更新を月2本の維持モードに落とし、時間をガイド/日本語教師など対人収益へ再配分（サイトは資産として残す＝閉鎖はしない） |
| CP5: 2027/12末 | 月2万以上（標準シナリオ軌道） | 8万目標を2028年へ再設定 or ポートフォリオ再編 |

- **家庭イベントを織り込む**：2027/1〜子作り開始予定→2027年後半は時間が減る前提。**記事は2026年中に前倒しで積む**（仕込み期に25本の根拠）。

## 6. 代替案との比較（この時間を他に使ったら）

| 選択肢 | 金銭（1年目） | 適合 |
|---|---|---|
| **TSH（本計画）** | 低（期待値 月3.3万@2027末） | ワクワク・需要実証あり・C/Dへの導線・ストック複利 |
| 社不ライフ強化 | 低〜中（既存56本の土台） | 本人の温度＝惰性。日本語SEO×広告はAI逆風の直撃帯 |
| パート前倒し | 高（月8万を早期確実） | 2026/12まで不可（傷病手当）。ストック性ゼロ。体調リスク |
| 何もしない（療養特化） | ゼロ | 回復には資するが「暇」が本人には毒にもなる（構造がないと崩れる） |

→ **2026/12までは TSH が構造的にベスト**（他の高収益選択肢が制度上封じられているため）。2027年以降は CP4 の結果でパート/対人収益との配分を決める＝「全張りしない」設計。

## 7. 結論（投資判断）

- **育てるべきか：YES。ただし「金融商品」としてではなく「複利のかかる自家農園」として。**
- 理由：現金リスクゼロ／需要の一次証拠あり／本人の適性・ワクワク・生活設計（家庭中心・在宅）と完全整合／他プロジェクトの土台になる／今は時間の機会費用が最も低い期間。
- 条件：(1) 月8万は**楽観シナリオ**と正しく認識する（標準は2〜4万）(2) チェックポイントを機械的に運用する (3) 週時間上限で健康を守る (4) 2027年のパート/対人収益の判断をこのサイトの成否に**依存させない**（家計はパート等で立て、サイトは上乗せ＆将来枠）。
