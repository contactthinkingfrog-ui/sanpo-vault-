# 月次分析ワークフロー（毎月1回。当時の声かけ「月次分析やって」）

> **役割分担**：本人＝下記の手順でデータを出す（コピペ or CSV or スクショ）。解釈・performance-log記録・次月の打ち手はこちらで書いていた。
> 分析対象月の翌月頭に実施（例：8月分を9月初旬に）。

---

## ユーザーがやること（毎月・計10分）

### A. Search Console（検索の状況）

1. https://search.google.com/search-console を開く → 対象プロパティ選択
2. 左メニュー **「検索パフォーマンス」→「検索結果」**
3. 期間を**過去28日**に設定し、上部の **「合計クリック数・合計表示回数・平均CTR・平均掲載順位」の4つの数字**をメモ（スクショでOK）
4. 下の表を **「クエリ」タブ→上位20行**、**「ページ」タブ→上位10行**、**「国」タブ→上位5行** それぞれコピペ（またはエクスポート→CSV）
5. 左メニュー **「インデックス作成」→「ページ」**：「登録済みページ数」と「未登録の理由」上位だけメモ

### B. GA4（サイト内の行動）

1. https://analytics.google.com を開く → 対象プロパティ選択
2. **「レポート」→「集客」→「トラフィック獲得」**：期間28日で、チャネル別（Organic Search / Referral / Direct / Organic Social）の**セッション数**の表をコピペ
   - ※Reddit流入は Referral の中。表の下で「セッションの参照元」に切り替えて **reddit** の行があれば含める
3. **「レポート」→「エンゲージメント」→「ページとスクリーン」**：上位10ページ（表示回数・平均エンゲージメント時間）をコピペ
4. **「レポート」→「ユーザー」→「ユーザー属性」→「概要」**：国別上位5つをメモ
5. （収益化後）**「収益化」**の概要数値もメモ

### C. その他（該当あれば）

- Etsy：ダッシュボードの月間「訪問数・注文数・売上」
- アフィ各社：管理画面の月間クリック・成約・確定報酬
- Reddit：投稿した場合は各投稿の表示回数・賛成率

---

## データを受け取ったあとにやっていたこと

1. **[[wiki/performance-log]]に月次レコードを追記**（下記テンプレ）。
2. **解釈**：
   - 伸びたクエリ/ページ→「なぜ伸びたか」を特定し、**同型の記事を次月の執筆キューに提案**
   - 表示多い×CTR低いページ→タイトル/メタディスクリプション改善案を出す
   - 掲載順位5〜15位のクエリ→リライト候補（あと一押しで1ページ目）
   - Reddit流入とOrganicの比率→チャネル戦略の配分確認
   - 国別分布→ペルソナ想定（日本在住/北米）とのズレ確認
3. **事業計画との照合**：[[00_設定/事業計画・収支予測_2026-2028]]のチェックポイント（CP1〜5）に対する進捗を1行で判定。
4. **次月の打ち手を3つ以内**で出していた。

## performance-logテンプレ

```markdown
## YYYY-MM
- GSC: クリックX / 表示X / CTR X% / 順位X.X ｜ 登録ページX
- GA4: セッションX（Organic X / Referral X / Direct X）｜上位ページ: …
- 収益: 広告¥X / アフィ¥X / POD¥X ＝ 計¥X（目標比 X%）
- 所見: （伸びた/落ちた理由の仮説）
- 次月の打ち手: ①… ②… ③…
- CP判定: CPx に対して 順調/注意/未達
```
