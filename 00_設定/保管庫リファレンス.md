## §1 フォルダ構成

```
散歩する主夫/
├── 00_設定/wiki-schema.md      ← 構成メモ（旧 CLAUDE.md）
├── README.md
├── 00_設定/                    ← 戦略・運用ルール・設計ドキュメント
├── 20_執筆中/_drafts/          ← 執筆中の記事
├── 30_公開済み/                ← 公開済み記事の管理ページ
├── logs/activity.md            ← 作業ログ（append-only・継続の要）
├── raw/                        ← 生ソース（原文として残している）
│   ├── 過去記事/  サイト固定ページ/  競合ウォッチ/  読者の声/
│   └── 外部ナレッジ/（_inbox／一次情報／専門家発信／体験談・コラム）
├── templates/                  ← 記事生成テンプレート
└── wiki/                       ← 知識ベース
    ├── index.md                ← 全ページカタログ
    ├── persona/  concepts/  entities/  sources/  questions/  design/
    ├── keyword-map-en.md       ← 検索意図マップ（英語圏版が現行）
    ├── voice-guide-en.md       ← 文体・トーン辞典（⚠️B6で作り直す）
    ├── content-architecture-en.md
    └── performance-log.md      ← 公開後
```

## §2 運用の事実

1. `raw/` は原文。ここは触っていない
2. ページの追加・更新は `wiki/` で行う
3. 新しいソースを足したら、関連する Wiki ページも更新していた
4. ページ間は `[[WikiLink]]` で相互リンク
5. 矛盾する情報にはフラグを立てていた
6. 決定・進捗は `logs/activity.md` に残している（チャット内だけで終わらせない）
7. お金・制度・収入の情報には出典URLと確認日を添えていた

### 5-2. YMYL区分（★英語圏版でも「お金・制度」部分は有効）

| テーマ | YMYL度 | 配慮 |
|---|---|---|
| 生き方・世間の目・価値観コラム | 中 | 断定回避・個人差注記・上から目線NG |
| 家事・段取り・散歩・暮らし | 低 | 通常配慮 |
| **給付金・税・社会保険・扶養** | **高** | **一次情報URL必須・最新年度確認・更新日記載** |
| **収入・副業・在宅ワーク・転職** | **高** | **誇大表現禁止（「誰でも月◯万」NG）・出典明記** |
| メンタル・夫婦関係の悩み | 中〜高 | 断定回避・専門家相談の明記 |

> 記事冒頭の相談窓口必須・希死念慮対応といった重いYMYL対応は不要。ただしメンタルに触れる記事では専門家相談への一文を添える。
> ★**英語圏版では「お金・制度（ビザ・銀行・税・保険）」がこの高YMYL帯に該当する。**

### 5-3. 日本語版の旧トーン規則（英語圏版では voice-guide-en が正）
