# 散歩する主夫Wiki

「散歩する主夫」（https://shufu-sanpo.com ／ 準備中）の知識資産・運用保管庫。
社不ライフWikiで実証済みの「書けば書くほど次が楽になる」運用方式を継承した、**独立ブランドのメディア保管庫**。

## これは何か
- WordPressメディア「散歩する主夫」を設計・執筆・運用するためのナレッジベース
- 大テーマ＝**主夫（の生き方）**（主夫になる方法／生き方・考え方／家事・段取り／家庭円満／お金／暮らし・趣味を横並びで）／小テーマ＝**散歩**
- ターゲット：家庭を主戦場にする/したい男性（キャリア伸び悩み既婚男性・価値観変化の20代男性・兼業主夫/育休パパ）
